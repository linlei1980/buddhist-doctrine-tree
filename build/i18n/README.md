# 英文版译名与译文

## 体例

- **译名以梵文／巴利文为准**，英文用学界通行译法，不以直译中文为准。
  例：`四圣谛` → Four Noble Truths（catvāri āryasatyāni）；`一念三千` → three thousand realms in a single moment of mind。
- **汉地自撰的概念**（如「一念三千」「六即佛」「五时八教」）无梵文对应，直接用通行英译，`en` 栏仍标 `—`。
- **宗派名**用罗马化：Tiantai ／ Huayan ／ Sanlun ／ Faxiang (Yogācāra) ／ Chan ／ Pure Land ／ Vinaya ／ Esoteric (Tantra) ／ Jushe (Kośa) ／ Chengshi (Satyasiddhi)。
- **人名**从学界拼法：Nāgārjuna、Vasubandhu、Asaṅga、Zhiyi、Jizang、Fazang、Zongmi、Daoxuan、Shandao、Huineng、Tsongkhapa、Atiśa、Buddhaghosa。
- **经典名**用通行译名，并保留汉译信息：
  `《俱舍论》` → *Abhidharmakośa-bhāṣya* (Abhidharmakośa, trans. Xuanzang)
  `《杂阿含经》` → *Saṃyukta-āgama* (Chinese: *Za Ahan Jing*, trans. Guṇabhadra)
  `《大智度论》` → *Mahāprajñāpāramitā-śāstra* (attrib. Nāgārjuna)
- **古典汉文引文**全译为英文，并保留汉文原句于括号或 note 中，便于核对。
- **拼音与关键词**：每个节点除 `name` 外提供 `aka`（拼音、通行的英文别称、梵巴词），用于页面内中英通搜。
  例：`四圣谛` → `["si sheng di","Four Noble Truths","catvari aryasatyani"]`

## 检索用别名规则

1. 汉语拼音，小写、不标声调、音节空格分隔（`si sheng di`）；
2. 英文通行名（`Four Noble Truths`），含常见异拼（`Four Truths`）；
3. 梵文／巴利文（`catvari aryasatyani`，去变音符）；
4. 关键英文关键词（`suffering`、`dependent origination`、`no-self`）。
