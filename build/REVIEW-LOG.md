首版完成后做过一次**全量校对**：英文译文按五批、中文内容按四批（含一组结构审查），
每批由一个独立审读者逐句比对，产出报告后由我逐条核实真伪、再决定是否采纳。

**报告共 149 条**（high 21 / medium 51 / low 77），覆盖 358 个节点次。
报告原文、批次输入与审计脚本都保留在本目录，可复核。

## 一、为什么值得留档

机器能查的只是**结构**：覆盖率、出处条数、链接与粗体、中文残留、era 合法性。
这一轮查出的最严重问题**全在语义层**，机器一条也查不出：

| 性质 | 实例 |
|---|---|
| 出处误标 | 四圣谛四定义（八苦、五取蕴、「二边／中道」）本为《相应部》56.11 的现代汉译，却挂在《杂阿含经》卷15 第379经名下——379 经全文只讲三转十二行相 |
| 译人张冠李戴 | 《不增不减经》原与《胜鬘经》并列作求那跋陀罗译，实为元魏 菩提流支译；《成唯识论》原注「窥基糅译」，该论题「玄奘奉诏译」 |
| 引文漏字／衍字 | 「观无我我所」漏掉第二个「无」，意思正好相反；《大智度论》原文作「一切法无我印」，原引衍出「无为法」 |
| 术语误读 | 「情有理无」的「情」是迷情（众生迷妄的认识），被译作 affection（贪爱），遍计所执性与依他起性的定义因之失真 |
| 所引定义被换 | 有部定义「色者，变坏义」译作 the nature of resistance——那是「质碍」，另一套定义 |
| **数据缺陷** | 文献→概念的关系被 `[:8]` 截断（444 条引用只画出 273 条，被砍掉的恰是被引最多的典籍）；**20 个节点完全不进年表**（era 取了年表未声明的值） |

## 二、方法

**分组**　英文按语言域分五批（r1 四谛三法印／r2 缘起业力与实践／r3 部派因明论诤／
r4 二谛三性如来藏／r5 判教宗派传播史）；中文按 A1 根本教义线／A2 印度部派与大乘／
B 中国宗派与传播史，另有结构组做全库数据自洽审查。

**规范**　每批都附 `REVIEW-SPEC.md`，只报限定类别的具体问题，并要求：

- `current` 必须从输入文件**逐字照抄**（便于精确定位）
- 给出 `basis`（某经某卷、学界通说、或「与另一节点 X 矛盾」）
- **不确定时不报**——宁可漏，不可错报

最后一条收效明显：A2 组主动放弃了两条证据不足的疑点（《俱舍论》卷20 的无表色、
《毗婆沙论》卷27 的心性本净），A1 组也放弃了三条压缩表述类的意见。

**核实**　报告不等于结论。逐条核对后**有未采纳**的例子：

- A1 组主张 craving 节点的「379经」应改 380——核对该经确含「欲爱、有爱、无有爱」，不改
- B 组指 three_realms 的「色界十七天 + 无色四天 + 欲界六天 = 27」与「二十八天」不合——
  原文已解释「各部派的数目不同」，属压缩表述，不改
- 一批自动检查误判了 11 处「文献定型晚于汉译流传」——该页 fix 栏指宗派在中国定型之时，
  trans 栏指所依经典译出之时，两者本可后先相错

## 四、这一轮暴露的流程问题（都已变成断言或纪律）

**1. 不要用零散字符串替换改内容。** 修正一处嵌套引用时把整段改坏（出现重复与错位粗体）。
此后改为「整段比对—精确重写」，并要求每条替换**断言唯一命中**。

**2. 替换要区分「链接化前」与「链接化后」。** `[[id|文字]]` 是后续自动添加的，
在链接化之后替换会把标记一并改坏——曾产生 `[[vipaka|[[vipaka|异熟]]]]` 双重链接，
也曾把链接 id 改成带变音符的形式，导致 19 处交叉引用断链。
现在替换走「去标记比对」，另加链接 id 合法性检查。

**3. 原版节点与新增节点的修改位置不同。** 这是本轮最容易走错的一步：

| 内容 | 改动位置 |
|---|---|
| 原版 129 节点（现 179 个人工节点中的一部分） | `build/build.py` 的校订块（从中解析原版 HTML 取初值） |
| 新增节点（content_*.py） | `build/content_*.py` |
| 英文译文 | `build/i18n/work/*.en.jsonl` |

改错位置的代价：白改一轮（`i18n/work/*.json` 与 `content_*.py` 对原版节点都无效），
英文题名的 `sources.json` 更是流水线的**输出**而非输入，改它不持久。

**4. 年份、经号之类的词不能靠数字替换改。** 「549」既是引证数也是吉藏卒年（549—623），
靠全局替换会误伤。

**5. 硬编码的对外数字会脱节。** 预览图的数字原为硬编码，一度落后两版；
现改为从 `data/buddhism.json` 读取。

# 第二轮：判准充分性校对（2026-09）

第一轮（上述五批英文、三批中文、一批结构）查的是「译得对不对」与「说得对不对」。
第二轮另立一维：**释义是否把概念讲清楚了**——读者读完能否判断「什么算它、什么不算」。

起因是从「正思惟」的「无嗔」「无害」是否讲清推演出来的：释义列了名词，是否都给了判准？
这一问之前几轮查不出，因为**每一句本身都没说错**。

## 三个反复出现的缺口类型

**① 数目名目型**（最多）——凡「固定数目 + 专有名称」处最易写成报菜名：
六因四缘五果十五项、十宗十名、化仪四教、三界二十八天、无色四定、三十七道品四组、
五下分结、禅支、六位心所、十如是、四土、四灌、五不翻。

**② 同名异义**（最隐蔽）——须明确指出「此处不是日常义」：
四无量心的「舍」不是不作分别；因明的「离分别」不是不作判断；
「常乐我净」的「我」非阿特曼；无表色之「色」、依他起之「有」。

**③ 成组体例不齐**——同组内一半界定一半只列名，比整组都不界定更易误导：
读者看到「五教」逐条解释了，会假定「十宗」也是（而十宗原本只列名）。

## 第二次暴露的机制缺陷：中英两版不同源

英文释义与出处只来自 `i18n/nodes.jsonl` 与各批 `.en.jsonl`，中文侧改动不会传播。
改中文而不改英文时，**从任何单页都看不出**——中文页正确、英文页也能读，只是英文停在旧版。
本轮共 49 个节点如此。已加两条构建时断言：

1. **中英出处条数必须逐一相等**（英文出处不能由中文侧新增，否则会回退显示中文原题）
2. **中英释义必须同步**（粗体数校验）——本轮由它抓出 49 处

这已是同一机制坑的第三次（前两次：英文文献链接错位 34 处、英文出处条数不符）。
三次的共同教训：**中英同构但不同源，任何单侧改动都必须显式同步，且须有断言兜住。**

## 三处独立校对修正了排查者的判断

| 原判断 | 独立校对后的结论 |
|---|---|
| 五戒缺性戒／遮戒分判 | 该节点已同体例，问题只是判准放错位置（以伴随特征占位） |
| 四无量心的「舍」需大改 | 下文「离偏私」可救，报 low 而非 high |
| 「十玄门」列名而不界定 | 十门全列且九门有释，属合格 |

若照原判断去改，会把正确内容改坏。故本轮规范明确：
**「短而判准完整的不报」**——只报缺失的判准，不报缺失的篇幅。
