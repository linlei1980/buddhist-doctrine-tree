# 中文内容校对规范

中文版是**原文**，不是译文。所以要查的不是「译得对不对」，而是**「说得对不对、前后是否一致」**。

## 输入

`build/review_zh/A.json`（印度与教义线）、`build/review_zh/B.json`（中国宗派与传播史）。
每项含

- `id`、`category`、`name`（节点名）、`sa`（梵巴原语）、`era`、`key`（是否重点节点）
- `desc`：释义正文（`\n\n` 分段、`- ` 列项、`**粗体**` 强调、`[[node_id|文字]]` 交叉引用）
- `tt`：年代三栏（`form` 思想形成 / `fix` 文献定型 / `trans` 汉译流传）
- `sources[]`：`t` 为出处题名（含卷品经号），`q` 为引文原文（可能为空）

## 只报告以下五类问题

1. **事实错误**：人名、地名、宗派归属、传承关系、教义主张的张冠李戴。
   例：把某主张归给另一派；把甲论师的话当作乙论师。
2. **出处可疑或错误**：所标卷次、品名、经号与内容不符；所引典籍不存在或名称错讹；
   引文与所标出处不对应（例如引文实出《大智度论》却标《瑜伽师地论》）。
   **不确定时不要报**——宁可漏，不可错报。
3. **引文与释义不符**：引文不足以支持该释义，或引文与释义所述相反。
4. **年代问题**：`tt` 三栏或 `era` 明显违背学界通说（如把公元 4 世纪的事系于公元前）；
   或同一节点内部年代自相矛盾（`form` 晚于 `fix`、`fix` 晚于 `trans` 而无说明）。
5. **内部不一致**：同一概念在不同节点说法冲突；同一典籍在不同节点题名或卷次不一；
   同一人物名用字不一。

## 不要报告

- 排版、标点、繁简、译名偏好（梵文拼写统一另有人处理）
- 交叉引用与粗体的位置（已由脚本全量校验）
- 观点立场之争（本页不作教义评判，宗派分歧并列呈现是有意为之）
- 「我认为应补充某内容」这类增补建议

## 输出

写入 `build/review_zh/<批次>.findings.json`，JSON 数组，每项：

```json
{
  "id": "节点 id",
  "field": "desc | tt.form | tt.fix | tt.trans | era | src[0].t | src[0].q",
  "severity": "high | medium | low",
  "problem": "一句话说明问题（中文）",
  "current": "当前文本中该片段的**原文照抄**（我要用它精确定位）",
  "suggested": "建议改为（若属事实错误则给出正解；若只是可疑则写「需核」）",
  "basis": "你的依据——如某经某卷、学界通说、或「与另一节点 X 矛盾」"
}
```

- `high`：事实错误、出处与内容不符、引文与释义相反
- `medium`：年代可疑、出处卷次可能错、同一概念前后矛盾
- `low`：名称用字不一、疑似笔误
- `current` 必须**逐字照抄**，不要改写、不要加省略号；同一节点同一字段只报一次
- 没有问题的节点不必出现；整批无问题写 `[]`

## 完成回报

输出路径、条数、severity 分布、你认为最严重的 3 条（附依据）。
