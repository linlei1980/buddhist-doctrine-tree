# 判准充分性校对（2026-09・第二轮）

这一轮查的是**此前四轮都查不出的一类问题**：释义是否把概念讲清楚了。

- 第一轮（英文译文校对，见 `build/i18n/review/`）查「译得对不对」
- 第二轮（中文内容校对，见 `build/review_zh/`）查「说得对不对」
- **本轮查「讲清楚了没有」**——读者读完能否判断「什么算它、什么不算」

之所以要另立一轮：前两轮全部通过后，仍存在「正语四条口业一个都没界定」这类问题——
因为**每一句本身都没说错**。

## 起因

从「正思惟」的「无嗔」「无害」是否讲清推演出来的：释义列了名词，是否都给了判准？
故按四条可查指标全库筛，再人工核对：

| 指标 | 说明 |
|---|---|
| A 列名不界定 | 列出若干名词却未说明各名的判准 |
| B 判准缺失 | 给出类别却未给区分标准 |
| C 体例不齐 | 同组内多数成员给了判准而个别没有 |
| D 同名异义 | 同词在此语境下与日常语或他派用法不同而未指出 |

## 三个反复出现的缺口类型

**① 数目名目型**（最多，占多数条目）——凡「固定数目 + 专有名称」处最易写成报菜名：
六因四缘五果十五项、十宗十名、化仪四教、三界二十八天、无色四定、三十七道品四组、
五下分结、禅支、六位心所、十如是、四土、四灌、五不翻。原因是数目本身给人「已交代」的错觉。

**② 同名异义**（最隐蔽，4 条）——须明确指出「此处不是日常义」：
四无量心的「舍」不是不作分别；因明的「离分别」不是不作判断；
「常乐我净」的「我」非阿特曼；无表色之「色」、依他起之「有」。

**③ 成组体例不齐**——同组内一半界定一半只列名，比整组都不界定更容易误导：
读者看到「五教」逐条解释了，会假定「十宗」也是（而十宗原本只列名）。

## 本轮暴露的机制缺陷（已加断言）

**中英两版不同源**。英文释义与出处只来自 `i18n/nodes.jsonl` 与各批 `.en.jsonl`，
中文侧改动不会传播过去。改中文而不改英文时，**从任何单页都看不出**——
中文页正确、英文页也能读，只是英文停留在旧版。

本轮共 49 个节点出现此情形（中文已补判准、英文仍旧）。现已加两条构建时断言：

1. **中英出处条数必须逐一相等**（此前英文出处不能由中文侧新增，会回退显示中文原题）
2. **中英释义必须同步**（粗体数校验）——本轮即由它抓出 49 处

这是同一个机制坑的第三次（前两次：英文文献链接错位 34 处、英文出处条数不符）。

## 三处独立校对修正了排查者的判断

值得记下来，因为它说明「多一双眼睛读同一段文字」的价值：

| 原判断 | 独立校对后的结论 |
|---|---|
| 五戒缺性戒／遮戒分判 | 该节点**已同体例**，问题只是判准放错位置（以伴随特征占位） |
| 四无量心的「舍」需大改 | 下文「离偏私」可救，报 low 而非 high |
| 「十玄门」列名而不界定 | 十门**全列且九门有释**，属合格 |

若照原判断去改，会把已经正确的内容改坏。故本轮的规范里明确写入：
**「短而判断完整的不报」**——只报缺失的判准，不报缺失的篇幅。
