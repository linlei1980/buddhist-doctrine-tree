# 早期版本存档

## `v1-原版.html`

2026 年 9 月 23 日的初版：129 个节点、223 条关系、335 条出处引证，九层结构。

保留此文件仅为记录修订过程——对照它可以看出第二版改了什么。**不建议阅读此版本**，其中有几处已知错误已在第二版改正：

- 南传「三相」的第二支被误题为「诸行是苦」，与第三支「诸法无我」内容重复，导致四法印缺「苦」一支；
- 「正命」条把论书的出家众五种邪命与经中的在家众不应经营的行业合成一个「五种」讲述，且后者无出处；
- 关系标签共 142 种（含 12 条以数字 1—12 标注的十二因缘支），无法按类检索；
- 有 57 个节点的层级标记与目录缩进不一致，5 个节点在目录中重复出现。

详细修订说明见页面内「本版修订说明」，或见仓库根目录的 [README](../README.md)。
